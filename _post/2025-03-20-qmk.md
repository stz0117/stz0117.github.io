根据QMK官网介绍安装QMK_MSYS

https://docs.qmk.fm/newbs_getting_started

QMK_MSYS进行如下配置

```shell
# 我选择设置qmk home folder到QMK_MSYS安装目录下，默认的在Windows用户目录，不是很喜欢
qmk config user.qmk_home=qmk_firmware

# Keychron K pro/max系列固件在这个branch下才有
qmk setup Keychron/qmk_firmware -b wireless_playground

# 先设置下，后面compile就不用指定kb km了
# 注意keyboard要一直选到最细的分支，只写keychron/k12_pro是不行的
qmk config user.keyboard=keychron/k12_pro/ansi/rgb
qmk config user.keymap=stz_keymap

qmk new-keymap
```
